# Insert

Insert adds new rows to a table.

---

# What is it?

An insert operation creates a new record in a database table.

Whenever your application stores new information—such as a new user, task, or product—you perform an insert.

In Drift, inserts are performed using the `into()` API.

---

# Why does it exist?

Databases store data as rows inside tables.

Without insert operations, your database would remain empty because there would be no way to add new records.

Insert operations are one of the four fundamental CRUD operations:

* **Create** → Insert
* **Read** → Select
* **Update** → Update
* **Delete** → Delete

---

# Syntax

## Basic Insert

```dart
await into(users).insert(
  UsersCompanion.insert(
    name: 'Alice',
    age: 25,
  ),
);
```

Explanation:

* `into(users)` specifies the target table.
* `insert()` creates a new row.
* `UsersCompanion.insert()` provides the values to insert.
* Auto-generated and default columns can be omitted.

---

## Inserting All Required Values

```dart
await into(products).insert(
  ProductsCompanion.insert(
    name: 'Laptop',
    price: 999.99,
  ),
);
```

Explanation:

* Required columns must be provided.
* Columns with default values are filled automatically by SQLite.

# Examples

## Simple Example

Insert a task.

```dart
await into(tasks).insert(
  TasksCompanion.insert(
    title: 'Learn Drift',
  ),
);
```

Explanation:

* A new task is added to the database.
* Columns with defaults or auto-generated values are handled automatically.

---

## Real-World Example

Registering a new user.

```dart
await into(users).insert(
  UsersCompanion.insert(
    name: 'Alice',
    email: 'alice@example.com',
    age: 25,
  ),
);
```

Explanation:

* A new user record is created.
* Drift validates the insert against the table's constraints before SQLite stores it.

---

# When to Use

Use insert when you need to:

* Register a new user.
* Create a new task.
* Save a new order.
* Add a product.
* Store application data for the first time.

Every new record begins with an insert.

---

# When NOT to Use

Don't use insert when:

* Modifying an existing row.
* Replacing an existing record.
* Removing data.

Instead, use:

* `update()` for modifications.
* `replace()` for replacing rows.
* `delete()` for removing rows.

---

# Best Practices

* Use companion classes for inserts.
* Let auto-increment columns generate their own values.
* Take advantage of default values.
* Validate user input before inserting.
* Handle insertion errors appropriately.

---

# Common Mistakes

## Providing auto-generated IDs

**Wrong**

```dart
await into(users).insert(
  User(
    id: 1,
    name: 'Alice',
    age: 25,
  ),
);
```

Explanation:

* Auto-incrementing IDs should usually be generated by SQLite.

**Correct**

```dart
await into(users).insert(
  UsersCompanion.insert(
    name: 'Alice',
    age: 25,
  ),
);
```

Explanation:

* SQLite automatically assigns the ID.

---

## Forgetting required columns

**Wrong**

```dart
await into(users).insert(
  UsersCompanion.insert(),
);
```

Explanation:

* Required columns must be supplied.

**Correct**

Provide all required values when constructing the companion.

---

## Using insert to modify existing data

**Wrong**

Calling `insert()` to change an existing user's information.

Explanation:

* Inserts always create new rows.
* They do not modify existing records.

**Correct**

Use `update()` when changing existing rows.

# Summary

Insert creates new rows in a Drift table. Using the `into().insert()` API along with companion classes provides a type-safe way to add data while allowing SQLite to handle auto-generated values and defaults. It is the primary operation for creating new records in your database.
