# Generated Columns

Generated columns are columns whose values are automatically calculated from other columns.

---

# What is it?

A generated column doesn't store a value that you manually provide. Instead, SQLite computes its value using an expression based on one or more other columns.

Whenever the referenced columns change, the generated column is automatically updated.

For example, instead of manually calculating a person's full name every time, the database can generate it from the first and last name.

---

# Why does it exist?

Sometimes a column's value is completely derived from other data.

Without generated columns, you would need to:

* Calculate the value in your application.
* Store the calculated value.
* Keep it synchronized whenever the source data changes.

This can lead to duplicated logic and inconsistent data.

Generated columns let SQLite handle these calculations automatically.

---

# Syntax

## Defining a Generated Column

```dart
class Users extends Table {
  TextColumn get firstName => text()();

  TextColumn get lastName => text()();

  TextColumn get fullName => text().generatedAs(
    firstName + const Constant(' ') + lastName,
  )();
}
```

Explanation:

* `generatedAs()` defines a column whose value is computed automatically.
* The expression uses other columns from the same table.
* `fullName` is generated by SQLite and should not be set manually.

---

# Mental Model

Think of a generated column as a spreadsheet formula.

```text
First Name    Last Name
    │             │
    └──────┬──────┘
           ▼
      Full Name
```

You edit the input values, and the calculated value updates automatically.

# Examples

## Simple Example

A products table that calculates the total value of the stock.

```dart
class Products extends Table {
  IntColumn get quantity => integer()();

  RealColumn get price => real()();

  RealColumn get inventoryValue =>
      real().generatedAs(quantity * price)();
}
```

Explanation:

* `inventoryValue` is calculated from `quantity` and `price`.
* You never provide a value for `inventoryValue` when inserting or updating data.

---

## Real-World Example

A task management application.

```dart
class Tasks extends Table {
  DateTimeColumn get createdAt => dateTime()();

  DateTimeColumn get dueDate => dateTime()();

  IntColumn get daysRemaining => integer().generatedAs(
    dueDate.dartCast<int>() - createdAt.dartCast<int>(),
  )();
}
```

Explanation:

* The generated column is computed automatically from the other date columns.
* Changes to either date automatically affect the generated value.

> **Note:** The exact expression depends on the calculation you're performing and SQLite's supported functions.

---

# When to Use

Use generated columns when:

* A value can always be derived from other columns.
* You want to avoid storing duplicate data.
* The calculation should always remain consistent.
* The value is frequently queried.

Examples include:

* Full names
* Total prices
* Discounts
* Inventory values
* Calculated metrics

---

# When NOT to Use

Avoid generated columns when:

* The value should be entered manually.
* The calculation depends on application logic.
* The value depends on external services or APIs.
* The calculation changes frequently.

Generated columns should only depend on data available within the same row.

---

# Best Practices

* Keep generated expressions simple.
* Use generated columns for deterministic calculations.
* Don't duplicate calculated values in normal columns.
* Let SQLite maintain generated values automatically.
* Document complex generated expressions.

---

# Common Mistakes

## Manually inserting generated values

**Wrong**

```dart
await into(users).insert(
  UsersCompanion.insert(
    firstName: 'John',
    lastName: 'Doe',
    fullName: 'John Doe',
  ),
);
```

Explanation:

* Generated columns are computed by SQLite.
* Their values should not be supplied manually.

**Correct**

```dart
await into(users).insert(
  UsersCompanion.insert(
    firstName: 'John',
    lastName: 'Doe',
  ),
);
```

Explanation:

* SQLite calculates `fullName` automatically.

---

## Storing duplicated calculated data

**Wrong**

```text
Price
Quantity
TotalPrice
```

Where `TotalPrice` is manually updated.

Explanation:

* The calculated value can become inconsistent if updates are missed.

**Correct**

Use a generated column so the value is always derived from the source columns.

---

## Using generated columns for unrelated logic

**Wrong**

Using a generated column to store values returned by an API.

Explanation:

* Generated columns can only calculate values from columns in the same row.

**Correct**

Store external values in normal columns.

# Summary

Generated columns automatically calculate their values from other columns in the same table. They eliminate duplicated data, reduce maintenance, and ensure derived values always remain consistent. By moving simple calculations into the database, you can keep your schema cleaner and avoid repetitive application logic.
